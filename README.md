# Claude

Minecraft projects by nlTarzan. Each project lives in its own folder.

| Folder | What it is |
|---|---|
| `Minecraft_Plugin/Structures` | The original "Structures" datapack: a resetting Ocean Monument. No longer used; its `.nbt` structures now live in nlT-Structures. |
| `Minecraft_Plugin/nlt-structures` | **nlT-Structures**, a Paper plugin (Minecraft 26.3+, Java 25) that resets structures, starting with the Ocean Monument. An admin manual and a code walkthrough are in its `docs/` folder. |
| `Minecraft_Plugin/nlt-races` | **nlT-Races**, a Paper plugin (Minecraft 26.3+, Java 25) for solo, group and points races on foot, by elytra or in vehicles, with leaderboards through PlaceholderAPI. The design and its decisions are in its `DESIGN.md`. |
