# Claude

Minecraft projects by nlTarzan. Each project lives in its own folder.

| Folder | What it is |
|---|---|
| `Minecraft_Plugin/Structures` | The "Structures" datapack: a resetting Ocean Monument. Its `.nbt` structures are also used by the plugin below. |
| `Minecraft_Plugin/resetting-structures` | **ResettingStructures**, a Paper plugin (Minecraft 26.2+, Java 25) that resets structures, starting with the Ocean Monument. A code walkthrough is in its `docs/` folder. |
| `Minecraft_Plugin/nlt-races` | **nlT-Races**, a Paper plugin (Minecraft 26.2+, Java 25) for solo, group and points races on foot, by elytra or in vehicles, with leaderboards through PlaceholderAPI. The design and its decisions are in its `DESIGN.md`. |
